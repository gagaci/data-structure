Algorithm
void hanoi(int n, char src, char aux, char dest) {
if (n == 1) {
// BASE CASE: just move it!
move(disk 1, src → dest);
return;
}
// STEP 1: park top n-1 disks on aux
hanoi(n-1, src, dest, aux);
// STEP 2: move bottom disk to dest
move(disk n, src → dest);
// STEP 3: move n-1 disks onto dest
hanoi(n-1, aux, src, dest);
}

💡 Current Step

The algorithm works by breaking the problem into smaller pieces. To move N disks, first move N-1 disks out of the way, then move the big disk, then put the N-1 disks back on top.
